# КОРОВАНЫ · кампания и PvP

Самостоятельная браузерная игра от первого лица по оригинальному ТЗ Кирилла. Создана с нуля для слепого музейного эксперимента: чужие реализации, их код, README и скриншоты не использовались. Из общих файлов прочитан только формат музейной карточки и таблицы.

**[Исходная музейная версия](https://rai220.github.io/korovany/gpt-6-astra/)** · [Скриншот](screen.jpg)

## Запуск

Нужны Go 1.23+ и Node.js 22.12+ (или 24 LTS). Three.js закреплён в `package-lock.json` и входит в сборку: CDN во время игры не требуется.

```sh
npm ci
make build
./bin/korovany
```

Откройте http://127.0.0.1:8080/arena/ для PvP или http://127.0.0.1:8080/ для одиночной кампании. Создайте комнату, передайте код другу и войдите во втором браузере. Сетевая кнопка есть в верхней части меню кампании.

Для игры в локальной сети:

```sh
./bin/korovany -addr :8080
```

Остальные игроки открывают `http://<адрес компьютера в сети>:8080/arena/`. В приглашении должен быть адрес, доступный другим игрокам: ссылка с `127.0.0.1` работает только на компьютере создателя. Если захват мыши недоступен по HTTP, остаются перетаскивание и стрелки. Для интернет-хостинга нужен доступный сервер и HTTPS/WSS через обратный прокси. По умолчанию сервер слушает только локальный интерфейс.

Для разработки запустите два процесса:

```sh
# Терминал 1: сервер с разрешёнными адресами Vite
go run ./cmd/korovany -origin localhost:5173,127.0.0.1:5173
# Терминал 2: клиент с автоматическим обновлением
npm run dev
```

Vite передаёт `/api` и `/ws` серверу на порту 8080. В обычном запуске Go раздаёт готовую папку `dist`; рядом с бинарником должна быть эта папка (или укажите `-assets /путь/к/dist`). Прямой запуск исходного `index.html` через `file://` заменён HTTP-сборкой. Сохранения кампании по-прежнему используют прежний ключ localStorage, но доступны только на прежнем origin: схема, адрес и порт должны совпадать.

## Сетевая схватка

Первый игровой срез — отдельная арена на 2–8 игроков, каждый сам за себя. Матч начинается после появления второго бойца и трёхсекундного отсчёта. Победа: 10 убийств или лучший счёт за 3 минуты; одинаковый счёт даёт ничью. Через 10 секунд начинается следующий раунд. Это ещё не командное ограбление движущегося корована.

- WASD — движение, Shift — бег, пробел — прыжок; мышь или стрелки — обзор.
- ЛКМ / F — клинок, ПКМ / B — направленный блок. Удары расходуют выносливость; стены закрывают цель.
- Смерть оставляет 3 секунды до возрождения. Короткая защита после появления снимается при атаке.
- P / меню — настройки и выход. Меню, потеря фокуса и скрытие вкладки не останавливают общий мир.
- При кратком обрыве клиент пробует вернуться с приватным токеном той же сессии. Сервер сохраняет бойца 20 секунд. Токен живёт в памяти вкладки; перезагрузка страницы считается новым входом.
- Комнаты и результаты хранятся в памяти; перезапуск сервера завершает матчи. Пустая комната удаляется через 30 секунд.

Сейчас транспорт — **WebSocket**, судья матча — Go-сервер. WebRTC/P2P, автоматический обход NAT/TURN, перенос хоста, компенсация задержки попаданий, лук и перенос кампании в сетевую симуляцию пока не реализованы. Хостить этот сервер на компьютере игрока можно, но это обычное клиент-серверное подключение, не автоматический P2P.

## Устройство сетевой части

- `internal/game` — чистая симуляция без браузера и сети: 60 фиксированных шагов в секунду, движение, бой, возрождение, фазы раунда.
- `internal/game/data/arena.json` — единые препятствия, точки появления и параметры. Go встраивает файл, TypeScript импортирует его при сборке. При изменении контракта карты нужно обновить `version` и пересобрать обе части.
- `internal/server` — HTTP, комнаты и адаптер WebSocket. Состоянием каждой комнаты владеет одна goroutine; обработчики соединений передают команды через ограниченную очередь. Медленный клиент не задерживает остальных. Максимум 64 комнаты.
- `client/protocol.ts` — типы сообщений; `network.ts` — подключение, ping и восстановление связи. Протокол и версия карты проверяются при входе.
- `client/simulation.ts` — предсказание собственного движения, повтор неподтверждённых команд после коррекции, буфер интерполяции остальных бойцов (100 мс). Снимки сервера отправляются 20 раз в секунду.
- `client/render` — сцена и модели. Генератор персонажей общий для кампании и сетевого клиента; игровые данные не содержат Three.js-объектов.
- `client/input.ts`, `client/main.ts` — управление и интерфейс. Кампания пока остаётся в `game.js`, кроме вынесенных моделей персонажей.

Клиент отправляет намерение движения и атаки, без координат, урона и длительности шага. Сервер проверяет диапазоны, монотонные номера команд, частоту сообщений, дальность и направление атаки, препятствия, выносливость, задержку между ударами и защиту после появления. За тик исполняется максимум одна команда игрока. Это основа серверной проверки правил, а не полноценная система античита.

`peer` в сервере и `Transport` в клиенте отделяют сеть от симуляции. Следующий этап для прямых соединений: адаптер Pion/WebRTC, сигналинг, ICE/STUN и TURN, отдельный запуск Go-хоста у игрока. Одной замены WebSocket недостаточно, чтобы обещать меньшую задержку или равные условия с хостом.

Дальше — ограниченная сервером компенсация задержки попаданий и испытания при задержке/потерях, командный режим сопровождения/ограбления корована, затем перенос NPC и других механик кампании. Полный рефакторинг одиночной симуляции и её привязки ко времени кадров остаётся отдельным этапом.

## Три судьбы

- **Лесной эльф:** отразить набег на деревянную деревню, ограбить корован, прорваться во дворец и поднять знамя леса. Начинает с луком и клинком.
- **Дворцовая стража:** войти в южные ворота, найти командира в золотом шлеме и получить приказ. Защитить дворец от троих шпионов и партизан, лично доложить, получить награду и двух спутников, уничтожить отмеченный дозор у старого форта, вернуться с докладом.
- **Злой. Имя не придумал.:** начать у старого горного форта с четырьмя воинами. Самостоятельно командовать: «за мной», «держать позицию», «на штурм дворца». Армия идёт по восточному тракту к южным воротам. Игрок участвует в бою и захватывает знамя после уничтожения защитников.

Каждая история имеет завершение и награду. Затем продолжается свободная игра. Примерно раз в 110 игровых секунд враги нападают на родное поселение; без защиты они разграбляют его и отнимают часть золота. Окна интерфейса ставят мир на паузу.

| Густой лес с LOD | 966 процедурно расставленных деревьев. В пределах 48 шагов — объёмные ствол и три яруса кроны. Дальше — нарисованная на canvas картинка, повёрнутая к камере. Геометрия и картинки сгруппированы в InstancedMesh. |
| Деревянные дома | Бревенчатые фасады, опоры, крыши, окна и крыльца; отдельные поселения людей и эльфов. |
| 3D-экшон | Клинок, лук, прицел, блок, бег, выносливость, прыжок и столкновения с деревьями, домами, скалами и стенами. Мышь с Pointer Lock; резервный обзор стрелками и перетаскиванием. |
| Враги и трупы в 3D | Объёмные персонажи, ходьба, удары, бой между фракциями и союзниками. Тело остаётся лежать и доступно для обыска; отделённые конечности падают на землю. |
| Грабёж корованов | Две движущиеся повозки с волами и двумя конвоирами каждая. E останавливает корован и вызывает бой; после победы E забирает золото и припасы. Через 110 секунд запас груза и охрана восстанавливаются. |
| Покупки | Четыре лавки с лекарями: бинты, стрелы, доспех, усиление оружия, наёмники, коляска, три протеза. Тратится реальное игровое золото; уровни улучшений и размер отряда ограничены. |
| Командир и самокомандование | Два последовательных приказа для стражи с личными докладами. Злодей управляет отрядом и штурмует дворец. Все фракции могут нанимать спутников. |
| Рука | Утрата ослабляет удары на 52% и вызывает смертельное кровотечение. Бинт / лекарь останавливает кровь, механическая рука возвращает силу. |
| Глаз | Утрата закрывает чёрным ровно левую половину экрана. Стеклянный волшебный глаз возвращает обзор. |

| Сохранения | localStorage: ручная запись F5, загрузка F9, автозапись каждые 60 игровых секунд и при уходе со страницы. Сохраняются фракция, прогресс, травмы, деньги, отряд, живые враги, трупы и их обыск, корованы и таймер набегов. Повреждённые записи отклоняются. |

Травмы игрока возможны при неблокированном попадании, когда здоровье ниже 83; между травмами есть 20 секунд передышки. Кровотечение само не останавливается. Врага можно ранить в руку, ногу или голову в зависимости от точки попадания; потеря ноги замедляет его, руки — ослабляет.

## Управление

| Клавиши | Действие |
|---|---|
| WASD, мышь | Движение и обзор |
| Shift, пробел | Бег и прыжок |
| ЛКМ, ПКМ | Атака и блок |
| 1, 2 | Клинок и лук |
| E | Лавка, разговор, ограбление, обыск, знамя |
| Q | Бинт: остановить кровь и вылечить 38 здоровья |
| C | Приказы отряду |
| M, J | Карта и журнал состояния |
| F5, F9 | Сохранить и загрузить |
| Esc или P | Пауза, звук, качество, чувствительность мыши |
| Стрелки | Резервный обзор без захвата мыши |

## Упрощения

Это законченная небольшая игровая диорама размером около 400 × 400 шагов, а не масштаб Daggerfall. Магазин — меню обмена, без интерьеров, сложной экономики и генерации городов. Дипломатия фиксирована: три воюющие стороны и нейтральные торговцы. Бой и движение войск используют простое локальное избегание препятствий и путевые точки; сложного поиска пути нет. Трупы и отлетающие конечности — стилизованные геометрические модели без физического ragdoll. У коляски видны объёмные колёса, подлокотники и подножка от первого лица; отдельной внешней модели игрока нет. Стеклянный глаз намеренно волшебный. Все иллюстрации и модели процедурные, без скачанных художественных ассетов.

Для ограничения нагрузки остаются до 20 тел и 24 отделённых частей. Лес рисуется несколькими пакетами, разрешение ограничено. Автоматическое качество снижает разрешение и отключает тени при низком FPS; обычное и лёгкое качество можно выбрать вручную. В этом окружении headless Chromium с программным SwiftShader показал около 13 FPS после автоматического снижения внутреннего разрешения до 704 × 440 при окне 1280 × 800. Это не замер на ноутбуке с аппаратным GPU; его производительность здесь не проверялась. Счётчик FPS включается в меню паузы.

## Проверка

```sh
make check                     # TypeScript, 9 клиентских тестов, Go с -race, go vet
make build
npx playwright install chromium
./bin/korovany                  # оставить работающим в отдельном терминале
npm run test:campaign           # регрессии одиночных механик и обычного запуска
npm run test:multiplayer        # два браузера: комната, движение, бой, меню, reconnect
```

Go-тесты проверяют движение, стены, направленный блок, дальность и частоту ударов, смерть и возрождение, лимиты комнаты, повторы/некорректные команды, возврат игрока и изоляцию комнат. Сетевые тесты используют реальные WebSocket-соединения и сверяют состояния двух клиентов. Общие численные сценарии движения из `movement_cases.json` запускаются в Go и TypeScript; клиентские проверки дополнительно проверяют коррекции, смену жизни и интерполяцию.

Кампания использует явные фикстуры `?test=1` для сложных состояний; в обычном запуске тестовый API отсутствует. Сетевой браузерный тест управляет реальными клавишами и наблюдает публичные сообщения сервера, без изменения игрового состояния через тестовый API. Для другого сервера укажите `ASTRA_URL=http://127.0.0.1:8080/` (с завершающим `/`). Проверки подключены к GitHub Actions.

`screen.jpg` — исходный скриншот одиночной игры. Приведённый выше старый замер SwiftShader относится к исходной кампании, а не к текущей сетевой арене. Проверка через localhost не заменяет испытания между разными сетями.
